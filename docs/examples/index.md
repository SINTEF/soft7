# Examples

This section contains examples for users on how to use SOFT7.

The `advanced` and `datasource` examples require the `oteapi` extra to be installed, i.e., `pip install 'soft7[oteapi]'`.

```{warning}
The OTEAPI-related functionality used in the `advanced` and `datasource` examples is deprecated.
It will be removed in a future version of SOFT7, see [#222](https://github.com/SINTEF/soft7/issues/222).
```
